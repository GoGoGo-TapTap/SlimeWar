# R5 警戒、粘液与探索行为手动验收

日期：2026-10-19

## 1. 启动

1. 打开 `/Game/_SlimeWar/Maps/L_Ecology_DoublePoint`。
2. PIE 后执行：

```text
SlimeRunStart
SlimeRunTimeScale 0
```

## 2. 粘液趋近

- [ ] 执行 `SlimeEcologyR5Test`。
- [ ] `stage 0` 为 `SeekPaint`，最近粘液约 70 cm。
- [ ] `stage 1` 最近粘液进入 50 cm 停止圈，个体停住而不继续绕行。
- [ ] 粘液目标只在采集休息期间选择；正常采集或返程时不会被粘液抢占。

## 3. 警戒后采集休息

- [ ] `stage 2` 显示 `AlertWait`。
- [ ] 清除警戒后 `stage 3` 的 `gatherRest` 约为 4 秒减去等待时间。
- [ ] 空载个体在休息期间不开始采矿。
- [ ] 携货个体警戒结束后继续返程，不进入 4 秒空载休息。

## 4. 探索历史

- [ ] 休息结束后 `stage 3/4` 为 `Explore`，`explorationVisits` 至少为 1。
- [ ] 反复探索同一网格后，个体更倾向选择较远、访问次数更少的候选点。
- [ ] 没有出现原地左右抖动或永久卡住。

## 5. 资源争夺消退

- [ ] 执行 `SlimeEcologyDisputeTest`。
- [ ] 日志显示 `decay 0.75 -> 0.25`。
- [ ] 争夺达到 1.5 秒后触发警戒，冷却为 5 秒。
- [ ] 条件消失时累计值下降，而不是立即清零或继续累加。

## 6. 数值冲突检查

- [ ] 未修改任何 `Recorded – No Change` 数值。
- [ ] 粘液感知 6 米、接近 65 cm/s、停止 50 cm 为新增行为参数。
- [ ] 探索历史 400 cm 网格、每次访问 5 米等效惩罚为新增行为参数。
