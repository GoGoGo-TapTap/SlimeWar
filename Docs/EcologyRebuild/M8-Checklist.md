# M8 警戒、手雷、粘液与计分手动验收

> 自动场景已通过。本清单验证真实键鼠输入、视觉反馈和完整回合体验。

## 1. 启动

1. 打开 `L_Ecology_DoublePoint`。
2. PIE，控制台执行：

```text
SlimeRunTimeScale 0
show collision
```

---

## 2. 手雷输入与库存

- [x] `1` 切换同化雷，HUD 选择状态变化。
- [x] `2` 切换旋风雷。
- [x] `Z` 选择 A 阵营，`X` 选择 B 阵营。
- [x] `G` 投掷当前手雷；飞行有重力、落地/撞墙后触发。
- [x] 两种手雷初始各 3 枚。
- [x] 连续投掷间隔约 0.7 秒。
- [x] 投完一种后无法继续投掷该类型。
- [x] HUD 显示手雷类型、库存和当前阵营。

---

## 3. 同化雷

1. 生成一群史莱姆：

```text
SlimeSpawnEcology 6 0 1
```

2. 选择同化雷 B 阵营，向群体投掷。
3. 执行：

```text
SlimeEcologyStatus
SlimeEcologyFusionStatus
SlimeGrenadeStatus
```

- [x] 半径约 4.5 米内个体变为 B 阵营。
- [x] 视觉/HUD 阵营颜色变化。
- [x] 正在融合的个体解除配对。
- [x] 核心战斗目标被清理。
- [x] 警戒、矿点记忆、货物记忆被清理。
- [x] 体量、生命、核心类型、货物和身体分不变化。
- [x] 个体所属站点同步改为新阵营站点。
- [x] 携货个体同化后不再返回旧站点，而是返程到新阵营站点。

---

## 4. 旋风雷

1. 清空并重新生成：

```text
SlimeClearEnemies
SlimeSpawnEcology 6 0 1
```

2. 选择旋风雷并向群体中心投掷。
3. 执行：

```text
SlimeEcologyBodyStatus
```

- [x] 半径约 6 米内个体被拉向中心。
- [x] 吸引速度达到但不超过 4.5 m/s。
- [x] 效果持续约 4.5 秒。
- [x] 吸引不会自动产生玩家撮合，也不会直接融合。
- [x] 墙体/货架等静态遮挡后的个体不会被吸引。
- [x] 结束后个体恢复普通外力阻尼和自主移动。

## 5. 警戒

### 玩家枪击

- [x] 射击普通史莱姆不会让其或同族进入警戒。
- [x] 普通史莱姆被玩家射击后仍不把玩家作为战斗目标。

### NPC 伤害

1. 让敌对核心跃击同族，或执行：

```text
SlimeEcologyAlertTest
```

- [x] 受害者先进入 1 秒预警。
- [x] 5 米内可见同族被通知。
- [x] 警戒总持续约 10 秒。
- [x] 不接力传播到 5 米外的第二批同族。

## 6. 争夺与敌对核心

- [x] 两个敌族在 3.4 米内且满足资源/携货/敌对核心条件时，累计约 1.5 秒触发警戒。
- [x] 条件消失后累计值下降。
- [x] 触发后 5 秒内不重复触发争夺警戒。
- [x] 单只警戒普通个体不会直接变敌对核心。
- [x] 警戒中的普通个体完成融合后生成敌对核心。

复现命令：

```text
SlimeEcologyDisputeTest
SlimeEcologyHostileFusionTest
```
