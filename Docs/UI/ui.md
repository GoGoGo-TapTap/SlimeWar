| 项                       | 归属                      | 具体动作                                                     | 要连线吗                                                     |
| :----------------------- | :------------------------ | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **准星 / 蓄力环**        | 纯 WBP                    | ① File → Reparent Blueprint → `SlimeAimPreviewWidget` ② 四个控件名严格对上：`Img_ChargeRing_Fill`、`Text_ChargePercent`、`Img_Crosshair_Default`、`Img_Crosshair_Weakpoint` ③ 环用 **Image + MI_ChargeRing**（不要 ProgressBar）④ 弱点准星默认 `Collapsed` | **不用**——C++ 的 Tick 直接读 `GetChargeAlpha()` / `IsCharging()` / `IsWeakpointLocked()` 并写材质参数，你在 WBP 里**不要写 Tick** |
| **手雷 UI**              | 纯 WBP                    | `Event On Grenade Inventory Updated(A, V)` → 两个 Text 填 ×A/×V，为 0 时对应 icon 置灰；`Event On Grenade Selection Updated(Type, Faction)` → 高亮当前、压暗另一个 | 要，两条事件                                                 |
| **站点 5 项**            | 纯 WBP                    | `Event On EcologySitesUpdated(Sites)` → 每项显示 阵营色 / LiveCount / LiveMass / DeliveredCount / CoreCount | 要，且**最重**（下面有个坑）                                 |
| **结算字段 + EndReason** | 纯 WBP                    | `Event On Result Ready(Result)` → Break → 填 Text；`EndReason` 走 `TimeUp / PlayerDied / Extinction` 三分支文案 | （ui未预留该位置无需连线）                                   |
| **选关锁定态**           | 纯 WBP                    | 4 张卡，每张调 `IsLevelAvailable(Index)` → 不可用置灰 + 不响应点击；显示名 `GetLevelDisplayName`、图 `GetLevelId` | 要（轻量）                                                   |
| **准备页俯瞰图**         | **资产 + 关卡**，不是连线 | 双点/三点各做一张俯瞰图，再在 `WBP_SlimePreparation` 的背景 Image 里按关卡换 Brush | 基本不用（换 Brush / 按 LevelId 分支）                       |
