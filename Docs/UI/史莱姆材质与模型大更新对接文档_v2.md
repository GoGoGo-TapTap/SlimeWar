## 一、材质变更

M_Slime_Base 已重构：

- 去掉了原来的 TintAggro / DangerTint / Lerp 攻击变色逻辑
- 现在只有一个 TintNormal 参数控制阵营色
- 新增效果：半透明（Opacity 0.7）+ Fresnel 边缘光 + 顶点抖动（果冻呼吸感）
- 新增参数：Opacity、RimStrength、JiggleSpeed、JiggleStrength

⚠️ 重要：DangerTint（CustomPrimitiveData index 1）已从材质中删除，如果代码里还在设置这个参数，请去掉，否则会有警告。（之前确认过好像没有设置过）

材质路径：Content/_SlimeWar/Enemy/Art/M_Slime_Base.uasset

## 三、新增模型配件

### 1. SM_Slime_Spike（尖刺）

- 圆锥型，原点在底部
- 攻击性核心状态时显示，普通状态隐藏
- 建议在史莱姆蓝图加两个 StaticMeshComponent：Spike_Left、Spike_Right
- 位置：身体左右两侧（X=±半径×0.7，Z=半径×0.3）
- 材质用对应阵营的 MI_Slime_FactionA/B/C

路径：Content/_SlimeWar/Enemy/Art/SM_Slime_Spike

### 2. SM_Slime_Core（内部核心）

- 二十面体球，直径约20cm，原点在球心
- 材质：MI_Slime_Core（深色不透明）
- 每只史莱姆默认显示，位置在身体中心（Z=胶囊半径×0.5）
- 需要身体半透明才能看到，M_Slime_Base 已设为半透明

路径：Content/_SlimeWar/Enemy/Art/SM_Slime_Core

### 3. SM_Slime_Weakpoint（弱点）

- 黄色小球，直径约12cm
- 材质：MI_Slime_Weakpoint（黄色不透明）
- 体量7/8时显示在史莱姆顶部，默认隐藏
- 用 USlimeWeakpointComponent 挂载

路径：Content/_SlimeWar/Enemy/Art/SM_Slime_Weakpoint

## 四、注意事项

- 三个阵营史莱姆保持半透明（Opacity=0.7），核心和弱点是不透明的
- 尖刺、核心、弱点都作为子组件附加到史莱姆身上，跟随体量缩放
- 攻击性核心靠尖刺区分，不靠颜色
- 同化是状态效果，不是独立阵营

## 五、游戏图标配置说明

游戏图标已做好：

- 源文件：T_GameIcon.png（256x256，已导入 UE，路径 Content/_SlimeWar/UI/Textures/）
- 打包用：T_GameIcon.ico（已转换为 ICO 格式，放在项目目录 E:\SlimeWar\Icon\）

配置方式（美术已配置好）：

- 位置：项目设置 → 平台 → Windows → 游戏图标
- 引用：E:\SlimeWar\Icons\T_GameIcon.ico
- ICO 包含多尺寸：16/32/48/64/128/256

注意事项：

- ICO 文件不需要导入 UE 内容浏览器，是项目级外部文件
- 打包时 UE 会自动读取该 ICO 生成 exe 图标
- 无需程序写代码对接
- 如后续更换图标，替换 ICO 文件即可，项目设置会自动引用新文件
